# Elektro-Bud — system magazynowy

## Wymagania

- Node.js
- npm
- Visual Studio Code

## Uruchomienie

1. Otwórz folder projektu w VS Code.
2. Otwórz terminal.
3. Wpisz:

npm install

4. Następnie:

npm run dev

5. Otwórz adres:

http://localhost:5173

## Budowanie projektu

npm run build
